Comandos
Herramientas
🔀

Git

Sistema de control de versiones distribuido. Gestiona el historial de tu código, ramas, fusiones y colaboración con otros desarrolladores.

📱

Termux

Emulador de terminal para Android. Ejecuta entornos Linux completos en tu dispositivo móvil, instala paquetes y desarrolla desde cualquier lugar.

🖥️

CMD

Símbolo del sistema de Windows. Ejecuta comandos, scripts .bat y administra el sistema operativo directamente desde la línea de comandos clásica.

⚡

PowerShell

Shell orientada a objetos de Microsoft. Automatiza tareas, gestiona el sistema y construye scripts avanzados con acceso completo al ecosistema .NET.

🟢

Vim

Editor de texto modal disponible en casi cualquier sistema Unix/Linux. Dominarlo permite editar código a alta velocidad sin abandonar el teclado.

🐍

Python venv

Entornos virtuales de Python. Aíslan dependencias por proyecto, evitando conflictos de versiones y manteniendo el sistema limpio.

🐧

Linux

Comandos esenciales de la terminal Linux/Unix. Navegación, gestión de archivos, permisos, procesos, red y administración del sistema.

🐙

GitHub CLI

Interfaz de línea de comandos oficial de GitHub. Gestiona repos, pull requests, issues, Actions y más sin salir de la terminal.

$_

Bash

Bourne Again SHell. Intérprete de comandos por defecto en la mayoría de sistemas Linux/Unix y macOS. Permite navegación, manejo de archivos y scripting avanzado.
